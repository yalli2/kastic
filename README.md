# KASTIC 2027 준비 가이드

KSEF 2027 **KASTIC**(Korea Adolescents Science & Technology Innovation Contest, CASTIC 2027 한국대표 선발전)을 준비하는 중·고등학생용 인터랙티브 단일 페이지 사이트입니다.

- 대회요강 · 공식 일정(D-day, .ics 캘린더) · 기간별 준비 체크리스트
- 과학프로젝트(논문·발표자료) 10단계 작성법 + 논문 뼈대 생성기
- 현장 과제수행 대비(5가지 과제 유형, CASTIC 2025 기출 분석, 120분 전략)
- 세부 분야 탐색 · 연습문제 · 실험설계 연습 · 점수 시뮬레이터
- 참고 수상작·보고서·기출 자료 링크

출처: 한국과학기술지원단 ksef.or.kr 공식 공고(2026.9.18). 비공식 정리 자료이며, 최종 정보는 반드시 공식 공지를 확인하세요.
